1. 如果沒有 cmd_vel
   → phase = STAND
   → body_shift / pre_lift / step_x 慢慢回到 0

2. 如果有 cmd_vel，而且目前是 STAND
   → 選目前的 swing_leg
   → phase = PRE_UNLOAD

3. PRE_UNLOAD
   → 抬腳前先卸重
   → body_shift 往安全方向移動
   → 用足力調整 z_offset
   → 如果 swing_leg 足力夠小，而且其他三腳安全
   → phase = SWING_FORWARD

4. SWING_FORWARD
   → swing_leg 抬起
   → 根據 cmd_vel 決定 step_x
   → 如果 cmd_vel_x > 0，往前擺
   → 如果 cmd_vel_x < 0，往後擺
   → 如果 cmd_angular_z != 0，左右腳 step_x 不同
   → 擺腳時間完成後
   → phase = TOUCHDOWN

5. TOUCHDOWN
   → swing_leg 慢慢放下
   → 如果 swing_leg 足力恢復
   → phase = RECOVER

6. RECOVER
   → body_shift 慢慢回中
   → z_offset 慢慢回 0
   → 短暫穩定一下
   → 換下一隻腳
   → phase = PRE_UNLOAD 或 STAND
